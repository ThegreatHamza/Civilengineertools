# Civil Engineer Tools

A professional mobile-first Civil Engineering Toolkit.

## Vision
Civil Engineer Tools is an offline-friendly Progressive Web App (PWA) designed for civil engineers, students, site engineers, and contractors.

## Features roadmap

- Quantity estimation system
- Individual construction calculators
- Formula library
- Unit converter
- Engineering notes
- Material database
- French and English interface
- Offline-first mobile experience

## Technology

Planned stack:

- React + Vite
- Tailwind CSS
- Progressive Web App features
- Local storage / IndexedDB

## Languages

- English
- Français
